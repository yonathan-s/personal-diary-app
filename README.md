# personal-diary-app

- This app allows users to create and view diary entries.

## Installation 

- `git clone <ssh>`
- `npm i`
- Create a `.env` file and create variables `PORT=3000` and `DB_URL=<Supabase_URL>`

## Setup Database

- `npm run setup-db` 

## Run the app

- `npm run start` to run in production mode

## Future Features

- Add functionality to update and delete entries on the frontend
- Add a sign up/login using auth
